# Servidores

## ¿Qué es un servidor web?

Un **servidor web** recibe peticiones HTTP de los clientes y devuelve respuestas, como páginas HTML o datos.

## Servidores habituales

- **Apache:** veterano y muy extendido
- **Nginx:** rápido y ligero
- **Node.js:** ejecuta JavaScript en el servidor

## Conceptos clave

1. Puertos (80 para HTTP, 443 para HTTPS)
2. Hosting y dominios
3. Despliegue
