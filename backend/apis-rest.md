# APIs REST

## ¿Qué es una API REST?

Una **API REST** permite que aplicaciones se comuniquen mediante HTTP usando recursos identificados por URLs.

## Métodos HTTP

- `GET`: leer datos
- `POST`: crear datos
- `PUT`: actualizar datos
- `DELETE`: borrar datos

## Buenas prácticas

1. Usar nombres de recursos en plural (`/usuarios`)
2. Devolver códigos de estado correctos (200, 404, 500)
3. Intercambiar datos en formato JSON
