# HTML básico

## ¿Qué es HTML?

**HTML** (HyperText Markup Language) es el lenguaje de marcado que da estructura a las páginas web.

## Etiquetas fundamentales

- `<h1>` a `<h6>`: títulos
- `<p>`: párrafos
- `<a>`: enlaces
- `<img>`: imágenes
- `<ul>` y `<li>`: listas

## Estructura mínima

1. `<!DOCTYPE html>`
2. `<html>` con `<head>` y `<body>`
