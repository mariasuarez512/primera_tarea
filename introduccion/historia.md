# Historia del desarrollo web

## Los inicios (1989-1995)

- **1989:** Tim Berners-Lee propone la World Wide Web en el CERN.
- **1991:** se publica el primer sitio web.
- **1993:** el navegador Mosaic populariza la web.

## La expansión (1995-2005)

- Nacen **JavaScript** y **CSS**.
- Aparecen las primeras tiendas online y buscadores.
- Se consolidan los lenguajes de servidor como PHP.

## La web moderna (2005 en adelante)

1. **Web 2.0:** contenido generado por los usuarios y redes sociales.
2. **Móvil:** el diseño responsive se vuelve imprescindible.
3. **Aplicaciones web:** frameworks como React, Angular y Vue.
