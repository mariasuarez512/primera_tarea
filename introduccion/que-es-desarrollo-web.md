# ¿Qué es el desarrollo web?

El **desarrollo web** es el proceso de crear, construir y mantener sitios y aplicaciones que funcionan en internet o en una intranet.

## Áreas principales

- **Frontend:** lo que el usuario ve e interactúa en el navegador.
- **Backend:** la lógica, los servidores y las bases de datos que hay detrás.
- **Fullstack:** quien trabaja en ambas partes.

## ¿Cómo funciona una web?

1. El usuario escribe una dirección en el navegador.
2. El navegador envía una petición al servidor.
3. El servidor procesa la petición y responde.
4. El navegador muestra el resultado.
